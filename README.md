# Eyes on the Road

Психологический хоррор от первого лица: непрерывная ночная поездка, диалоги с попутчиком, эмоциональное состояние которого влияет на реплики, события и (в перспективе) концовку.

| | |
|---|---|
| Движок | Unity 6, URP, C# |
| Платформа | Windows (ПК) |
| Прототип | `Assets/Scenes/DrivingPrototype.unity` |
| Жанр | атмосферный психологический хоррор, ретро-эстетика |

---

## 1. Цели прототипа

1. Кинематическое вождение по сплайну.
2. Собственная диалоговая система с выбором, таймером и молчанием как выбором.
3. Эмоциональная модель попутчика (две шкалы → четыре состояния).
4. События по триггерам: фиксированные и зависящие от состояния / флагов.
5. Расширяемый каркас сюжета

---

## 2. Принципы архитектуры

Контент разделён по ответственности:

| Слой | Где правится | Ответственность |
|---|---|---|
| Порядок сюжета | Hierarchy: `Events / Story`, `Events / Ambient` | Что за чем происходит |
| Текст диалогов | `Assets/_Project/Data/Dialogue/*.dialogue` | Реплики, ответы, сдвиги эмоций, флаги |
| Пространство и визуал | Сцена, Timeline, AudioSource | Позиция маркера, скример, звук, модель |

Ориентир по темпу повествования — линейные эпизоды в духе *Fears to Fathom*: костяк шагов + локальные скриптованные моменты внутри шага.

Не используется: единый «директор» со всеми событиями в одном скрипте с захардкоженными дистанциями; хранение сюжета и реплик в одном текстовом файле.

---

## 3. Вождение

Компонент `SplineDriver` на объекте машины.

- Движение по `SplineContainer` без физики колёс и Rigidbody.
- Ввод: газ, тормоз, смещение по полосе (Input System).
- Вспомогательный API: `TryEvaluateAtDistance` — позиция / касательная / up на заданной дистанции вдоль дороги (маркеры событий, постановка объектов перед машиной).

## 4. Диалоговая система

### 4.1. Компоненты

| Класс | Роль |
|---|---|
| `DialogueScript` / `DialogueEpisode` | Данные после импорта `.dialogue` |
| `DialogueLine` / `DialogueAnswer` | Реплика, варианты по состоянию, ответы, флаги |
| `DialogueRunner` | Логика: очередь реплик, таймер, выбор, события `ChoiceMade` / `EpisodeFinished` |
| `DialogueView` | UI: текст, кнопки, полоска таймера, ввод |
| `DialogueStackLayout` | Раскладка панели |

Создание ассета: **Assets → Create → Eyes on the Road → Dialogue Script**.

### 4.2. Формат `.dialogue`

```
# EpisodeName
Текст реплики попутчика
  близость: …
  привязанность: …
  безразличие: …
  враждебность: …
  1) Текст ответа [+3 / -2]
    флаг имя
  2) …
  3) …
  молчание [0 / +4]
    флаг имя
  таймер 8
```

Правила:

- до трёх ответов; сдвиг — `[расположение / накал]`;
- строка `флаг …` пишется под ответом или под `молчание` (несколько имён через запятую);
- при наличии ответов показывается таймер; истечение = выбор «молчание»;
- без ответов реплика скрывается по времени, полоска таймера не показывается;
- повторное нажатие цифры уже выбранного ответа подтверждает выбор.

## 5. Эмоциональная система

Компонент `CompanionEmotions`.

| Параметр | Описание |
|---|---|
| Расположение, накал | Независимые шкалы 0–100 |
| Состояния | Тихая близость; навязчивая привязанность; безразличие; враждебность |
| Гистерезис | Вход в «высокий» при 70, выход при 55 |
| Влияние | Текст реплик (`TextFor`), условия `Story Event`, в перспективе — концовки |

Отладка: клавиши **5–8** принудительно задают состояние.  
`PrototypeDebugHud` отображает скорость, дистанцию, шкалы, состояние и активные флаги.

## 6. Система событий

### 6.1. Корневой объект

На сцене: объект `Events` с компонентами:

| Компонент | Назначение |
|---|---|
| `EventDirector` | Исполняет детей `Story` по порядку; запускает `Ambient` при свободном слоте |
| `StoryFlags` | Хранит флаги; слушает выборы в диалоге |

В Inspector у `EventDirector` указываются ссылки на дочерние объекты **Story** и **Ambient**.

Поведение режиссёра:

- сюжетный шаг не начинается, пока занят предыдущий (диалог / действия);
- ambient ждёт свободного слота и паузы `Ambient Gap` после последнего события;
- сюжет имеет приоритет над ambient;
- если у шага задан `Max Wait` и ожидание превышено — шаг пропускается с логом в Console.

### 6.2. Story и Ambient

| Контейнер | Смысл | Порядок |
|---|---|---|
| `Story` | Обязательный каркас поездки | Дети сверху вниз, строго по очереди |
| `Ambient` | Побочные / атмосферные события | Независимо, через режиссёр; не ломают каркас |

Именование шагов рекомендуется с префиксом номера: `01 Intro`, `02 Radio`, …

### 6.3. Как создать новый шаг

1. Hierarchy: ПКМ по `Story` или `Ambient` → **Create Empty**, задать имя.
2. Добавить **обязательно** `Story Event`.
3. Добавить **один или несколько триггеров** (когда шаг становится готовым). Если триггеров нет — шаг готов сразу после «вооружения» (для Story — после конца предыдущего).
4. Добавить **действия** в нужном порядке (компоненты сверху вниз = порядок выполнения).
5. Для точки на дороге: в `Road Point Trigger` указать метры и нажать **Поставить на дорогу**.
6. Назначить ссылки (эпизод, AudioSource, PlayableDirector, целевой объект).

Несколько триггеров на одном шаге: готовы все должны сработать (логика «И»).

## 7. Справочник компонентов события

### 7.1. Ядро — `Story Event`

Обязателен на каждом шаге.

| Поле | Назначение |
|---|---|
| Mood | Условие по эмоциям: любое / высокий·низкий накал / высокое·низкое расположение / конкретное из четырёх состояний |
| Required Flag | Шаг только если флаг уже установлен |
| Blocked Flag | Шаг пропускается, если флаг установлен |
| Max Wait | Максимум секунд ожидания занятого режиссёра; `0` — ждать без ограничения |

Условие проверяется один раз в момент готовности. При неуспехе шаг пропускается навсегда (в рамках сессии).

---

### 7.2. Триггеры (когда)

Базовый тип: `StoryTrigger`. На объект вешаются конкретные реализации.

#### `Road Point Trigger`

Срабатывает, когда `SplineDriver.DistanceAlongRoad` достигает заданной дистанции.

| Поле / UI | Назначение |
|---|---|
| Distance Meters | Дистанция вдоль дороги в метрах (`0` — старт) |
| Кнопка «Поставить на дорогу» | Переносит объект к точке на сплайне и кадрирует Scene |

В Scene (при включённых Gizmos) рисуется точка срабатывания и подпись с метрами.

#### `Delay Trigger`

Срабатывает через N секунд после того, как шаг «вооружён» (в Story — после завершения предыдущего шага).

| Поле | Назначение |
|---|---|
| Seconds | Задержка в секундах |

Типичное применение: пауза перед Intro, пауза между сюжетными битами без привязки к дороге.

#### `Flag Trigger`

Срабатывает, когда указанный флаг появляется в `StoryFlags`.

| Поле | Назначение |
|---|---|
| Flag | Имя флага |

Можно комбинировать с `Road Point Trigger` (например: «после флага и после километража»).

---

### 7.3. Действия (что)

Базовый тип: `StoryAction`. Общее поле:

| Поле | Назначение |
|---|---|
| Wait Until Done | Если включено — следующее действие ждёт окончания текущего |

Порядок выполнения = порядок компонентов `StoryAction` на объекте сверху вниз.

#### `Play Episode Action`

Запускает эпизод диалога и (при Wait Until Done) ждёт его завершения.

| Поле | Назначение |
|---|---|
| Episode | Ссылка на `DialogueEpisode` (саб-ассет из `.dialogue`) |

#### `Play Timeline Action`

Запускает `PlayableDirector` и ждёт `duration` таймлайна.

| Поле | Назначение |
|---|---|
| Timeline | Ссылка на Playable Director |

Для скримера: Activation Track или Control Track с **Control Activation** на визуальном объекте; **Play On Awake** у Director выключен.

#### `Play Sound Action`

| Поле | Назначение |
|---|---|
| Source | AudioSource |
| Mode | Включить / выключить |

Для зацикленной музыки (`loop`) действие не блокирует сюжет после `Play`.

#### `Wait Action`

| Поле | Назначение |
|---|---|
| Seconds | Пауза между действиями |

#### `Set Flag Action`

| Поле | Назначение |
|---|---|
| Flag | Установить флаг из кода шага (не из диалога) |

#### `Place Ahead On Road Action`

Ставит объект на дороге **перед машиной** в момент выполнения (для скримера, чтобы не быть видимым заранее на обочине).

| Поле | Назначение |
|---|---|
| Target | Объект для перемещения |
| Ahead Meters | Дистанция впереди по сплайну |
| Side Meters | Смещение в сторону от оси дороги |

Обычно сочетается с `Play Timeline Action` (показ) или отдельным включением объекта.

---

### 7.4. Флаги — `StoryFlags`

Источники флагов:

1. Строка `флаг …` в `.dialogue` под ответом / молчанием.
2. Действие `Set Flag Action`.

Использование: `Required Flag` / `Blocked Flag` у `Story Event`, триггер `Flag Trigger`, будущие концовки.

---

## 8. Типовые схемы шагов

### 8.1. Диалог через N секунд после предыдущего

Компоненты: `Story Event` → `Delay Trigger` → `Play Episode Action`.

### 8.2. Реплика / звук на километраже

`Story Event` → `Road Point Trigger` → (`Play Sound Action`) → `Play Episode Action`.

### 8.3. Условный скример перед машиной

`Story Event` (Mood = высокий накал, Max Wait по необходимости) → `Road Point Trigger` → `Place Ahead On Road Action` → `Play Timeline Action` → `Wait Action` → `Play Episode Action`.

### 8.4. Ambient-атмосфера

Дочерний объект `Ambient`: `Story Event` + триггер + лёгкое действие (звук). Режиссёр не запустит его во время сюжетного диалога / скримера.

### 8.5. Музыка с начала поездки

Первый ребёнок `Story` без задержки (или с `Delay = 0`): AudioSource + `Play Sound Action` (loop). Следующий ребёнок — Intro с `Delay Trigger`.

## 9. Структура сцены (прототип)

```
Events
├── EventDirector
├── StoryFlags
├── Story
│   ├── 01 Intro
│   ├── 02 Radio
│   └── 03 RoadsidePerson
└── Ambient
```

Конкретные ссылки и клипы настраиваются в редакторе. Визуальный объект скримера (`RoadsidePerson`) хранится отдельно и по умолчанию выключен.
